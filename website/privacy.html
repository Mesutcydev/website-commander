Privacy overview

Keep the keys local.
Keep the boundary clear.

Website Commander is designed as a local Mac tool. It connects to the services you choose, stores credentials in the macOS Keychain, and keeps repository changes visible before they are committed.

Last updated: August 2026

On this pageData and credentialsProvider requestsRepositories and contentYour control

Data and credentials

Provider API keys, GitHub credentials, and deployment secrets are stored in the macOS Keychain. Workspace preferences and non-secret configuration can be stored locally and, where enabled by the app, synchronized through iCloud. Secrets are not included in workspace sync.

Provider requests

When you configure an AI provider or GitHub, Website Commander sends requests directly to that service. The app does not operate a proxy service for those requests. Each provider may process data according to its own terms and privacy policy.

Repositories and content

The agent reads repository files to understand a request and may stage changes in the local workspace. Repository files, rendered pages, and other connected content are treated as untrusted input. Do not place credentials or private information in a repository unless you intend to share it with the services you configure.

Your control

Changes are staged for review before a commit. Review generated code, deployment settings, and provider responses before approving work. Website Commander does not guarantee that generated code is correct or secure; you remain responsible for the changes you approve and deploy.

Open source

The source is available on GitHub. For security reports, use the repository’s security guidance.
