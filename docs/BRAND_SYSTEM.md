# Website Commander brand system

## Living Tab

The Living Tab combines a compact browser-tab silhouette with one four-point
command spark. It represents a controlled path from intent to code to preview.
Use the gradient mark for the app shell, primary empty states, and active-agent
moments. Use the monochrome mark in dense or neutral contexts. Never add text
inside it, rotate it, add glow, or animate it continuously.

The mark must remain readable at 16, 20, 24, 32, and 64 points. Its only brand
motion is a one-time spark reveal; Reduce Motion replaces this with an immediate
appearance.

The indigo-to-muted-teal gradient is reserved for the brand mark, primary actions,
active navigation, selected segmented controls, and meaningful progress.

## Type, spacing, and geometry

Use the native macOS system face and SF Mono for hashes, paths, branches, and
technical identifiers. Normal UI type ranges from 11–16 points; page titles are
18–20 points. Use the existing 4-point spacing scale. Controls are 28–40 points,
compact cards use 10-point radii, panels 12 points, and preview frames 16 points.

## Elevation and borders

Create depth with luminance: canvas → surface → raised → hover. Borders clarify
boundaries and focus, not every container. Avoid card-inside-card layouts, heavy
shadows, generic glass, neon glow, and large gradients.

## Icons and states

Use SF Symbols only, normally 14–17 points. Do not place routine navigation icons
inside colored squares. Components must provide visible hover, pressed, focus,
selected, disabled, loading, error, and success states as applicable. Status
must never rely on color alone.

## Motion

Immediate feedback is 120 ms, hover/press 160 ms, standard transitions 200 ms,
panels 250 ms, and preview resizing about 300 ms with a restrained spring.
Movement is limited to 1–6 points and communicates hierarchy or state. Respect
Reduce Motion and never run ambient brand animation.

## Correct usage

- One Living Tab mark at the shell entry point.
- Gradient only for high-value state and action.
- Compact, sentence-case labels.
- Honest empty and unavailable states.

## Incorrect usage

- Repeating the mark on every card.
- Gradient text, glow, or animated ambient backgrounds.
- Invented data, charts, provider logos, or status.
- Oversized rounded cards and icon tiles for routine actions.
