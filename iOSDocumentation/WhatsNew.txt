SiteAgent 1.15 — OpenRouter Free + LongCat

• Added OpenRouter Free as a free-tier assistant option
• OpenRouter Free uses the official `openrouter/free` capability-aware router
• OpenRouter Free shares your OpenRouter API key while keeping paid OpenRouter models behind Super
• Added first-class LongCat API support with LongCat-2.0
• LongCat supports streaming chat through its OpenAI-compatible API
• LongCat keys are stored securely in Keychain

What to test:
1. On the free SiteAgent tier, select OpenRouter Free and save an OpenRouter key.
2. Confirm the only available model is `openrouter/free`.
3. Send a coding request and confirm SiteAgent can stream a response and run tools.
4. With Super enabled, select LongCat and save a LongCat API key.
5. Confirm LongCat-2.0 is selected and a text-only coding request completes.

Smart Routing checks:
1. Open Settings → Assistant and enable Smart Auto-Routing.
2. Tap Configure Smart Routing and choose Quality, Code, or Budget.
3. Confirm only providers you connected with a valid key or sign-in appear.
4. Turn providers on or off, then choose a preferred model for each enabled provider.
5. Send “Fix the typo in the hero title” and confirm the request completes.
6. Send “Audit the whole site and plan improvements across every page” and confirm a capable planning/bulk model is used.
7. Attach an image and request a visual change; confirm Smart Routing uses an image-capable provider.
8. Reopen Configure Smart Routing and confirm provider and model choices were saved.
